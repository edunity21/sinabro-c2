# 시나브로 넷 · 편집 디자인판

9개 메뉴와 기능을 유지하면서 사진 표지와 특집 지면으로 다시 디자인한 버전입니다. 내용은 2026. 9. 29. 보고서 수정본(일정 및 검증 계획 수정)에 맞추었습니다.

## 2026. 10. 5. 수정 사항

- 사전(3월)·중간 성찰(7~8월) 조사는 문항이 달라 직접 비교하지 않도록 정리: 효과크기·유의성 주장과 사전·사후 기울기 도표 제거
- 성과 메뉴를 「중간 자료와 최종 검증 계획」으로 재구성: 3월 사전 진단 → 7~8월 중간 성찰 → 10월 최종 검증(예정) → 11. 3. 보고서 제출
- '사후 조사' 표기를 '중간 성찰'로, '열에 아홉' 표현을 긍정 응답 11.5%로 수정
- 일정 수정: 공개수업 1회 완료·2차 11. 20. 예정, WE 활동 10월 마무리 예정, 연구 일정 막대에 10월·11. 3. 추가
- 보고서 전문(report.html)의 요약·연구 설계·결론·부록을 수정본 문장으로 교체, 부록 효과크기 인포그래픽 제외
- 영문 장식 문구를 한국어로 교체, 보고서 표지 라벨 잘림·왼쪽 메뉴 줄바꿈·모바일 표지 글자 간격과 탭 줄바꿈 수정

## 달라진 디자인

- SINABRO 마스트헤드와 실제 공연 사진을 결합한 잡지 표지
- 네 글자를 클릭하는 원본 탐색 기능을 표지 위에 유지
- 각 과제 도입부를 제목·질문·수업 사진이 나란히 놓이는 특집 지면으로 구성
- 큰 번호의 활동 카드, 검은 4단 수업 절차, 사진이 붙은 플랫폼 자료 카드
- 성과·기록·자료실에 각기 다른 영문 지면 제목 적용
- 원본 사진 전체와 보고서 전문, 부록 유지
- 홈 메뉴의 밝은 사각형 없이 얇은 밑줄로 현재 위치 표시

## GitHub 업로드

1. 저장소에 이 폴더 안의 파일과 img 폴더를 모두 업로드합니다. ZIP 자체를 올리는 것이 아닙니다.
2. 저장소 맨 위에 index.html이 보여야 합니다.
3. Settings → Pages에서 Deploy from a branch, main, /(root)를 선택하고 Save합니다.
4. 배포 후 Pages 화면에 표시된 주소로 접속합니다.

별도 빌드는 필요하지 않습니다. 기존 버전과 비교하려면 새 저장소를 사용하세요. 실제 업로드는 이번 작업에 포함하지 않았습니다.
